توقعات وائل الزين — LIVE V5

ما الجديد:
- واجهة عربية RTL أكبر وأكثر ترتيبًا.
- نافذة تحليل كبيرة جدًا، وتصبح ملء الشاشة تقريبًا على الهاتف.
- خيارات: 7 أيام، 14 يوم، 30 يوم، الشهر القادم كاملًا.
- رفع حد جلب المباريات العامة إلى 500 مباراة بدل التوقف المبكر عند 120.
- ترجمة عربية للدول والبطولات المعروفة مع إبقاء أسماء الفرق الرسمية.
- كود WZ جديد فريد لكل تحليل مع زر نسخ مباشر.
- بقاء التحليل العميق عبر API-Football عند إضافة API_FOOTBALL_KEY، مع TheSportsDB كخيار عام احتياطي.

للتحديث على GitHub:
1) استبدل server.js الحالي بهذا server.js.
2) استبدل package.json الحالي بهذا package.json (اختياري لكنه يصحح أمر start إلى node server.js).
3) ارفع التغييرات إلى فرع main.
4) Render مضبوط مسبقًا على: Build Command = npm install / Start Command = node server.js / Root Directory فارغ.
5) Auto-Deploy سيبدأ تلقائيًا بعد تحديث GitHub.
